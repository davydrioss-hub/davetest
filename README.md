# After Hours — Night Shift 0.2

Небольшая кооперативная игра о вечерних доставках и развитии своей компании.
Стилизованный трёхмерный район, гараж, фургон, контракты и смены на 20 минут.
Это ранняя играбельная версия, рассчитанная на частную игру с друзьями.

## Как запустить Windows-версию

1. Распакуйте **весь** `AfterHours-Windows.zip`.
2. Откройте `AfterHours/AfterHours.exe`. Файл `AfterHours.pck` должен лежать рядом.
3. При первом запуске введите никнейм.
4. Для одиночной игры: **PLAY → SINGLE PLAYER → START GAME**.
5. Откройте планшет **Tab**, примите обычный заказ и следуйте вкладке «Помощь».

Windows x64; требуется видеодрайвер с поддержкой OpenGL 3.3. Начальная настройка
окна — 1280×800. В SETTINGS можно включить полный экран, отключить тени и
сглаживание, изменить громкость и музыку. Минимальные требования к конкретным
видеокартам и процессорам пока не измерены.

## Играть с друзьями

- Хост: **PLAY → HOST GAME**, имя сервера, лимит 2/4/8, необязательный пароль,
  новый мир или сохранённый слот, **START GAME**.
- Друзья: **PLAY → JOIN GAME**, IP хоста, пароль, **CONNECT**.
- Пример адреса: `192.168.1.50` или `192.168.1.50:27020`.
- Транспорт — UDP, порт по умолчанию **27020**. Разрешите игре доступ к частной
  сети в диалоге брандмауэра Windows, если он появится.
- Через интернет нужен доступный публичный IP с перенаправленным UDP-портом
  либо общая виртуальная LAN. Самостоятельного сервиса поиска серверов,
  ретранслятора или автоматического обхода NAT нет.
- Все участники используют одну версию архива. В фургоне 4 места, в сессии —
  до 8 игроков: оставшиеся могут заниматься складом или доставлять пешком.
- При выходе хоста сессия завершается с сообщением **Host disconnected.**

Steam, Epic, аккаунты игроков, магазины и лаунчеры не используются. Для
одиночной и LAN-игры интернет не нужен. Одиночная игра использует те же правила
сервера, что и кооператив.

## Что делать в игре

Компания начинает с $650, гаража и фургона. Контракт создаёт груз на площадке
перед гаражом. Перенесите его в багажник, закрепите, отвезите по адресу на карте
и передайте получателю в руках. Оплата поступит в общий бюджет компании.

| Контракт | Особенность |
| --- | --- |
| Обычный | Простая доставка в один пункт |
| Срочный | 3 минуты с момента принятия; опоздание уменьшает оплату |
| Хрупкий | Сильнее повреждается при столкновениях |
| Тяжёлый | Занимает 3 ячейки; вдвоём переносится быстрее, одному доступна тележка |
| Несколько адресов | Промежуточная отметка и оплата после последнего пункта |

У остальных контрактов срок 12,5 минуты, также ограниченный концом смены.
Новые клиенты открываются с репутацией 2. Вначале доступны 2 активных заказа.

Смена длится 20 минут. Цель первой — $1600 чистой прибыли. В расходы входят
ремонт, топливо, улучшения и до $80 обслуживания в конце смены. Итоги видны в
**Tab → Компания**. Хост может закончить смену досрочно у терминала; незавершённые
заказы закрываются без оплаты. Следующая смена сохраняет бюджет, репутацию и
улучшения, меняет маршруты и обновляет контракты.

Дождь, перекрытая улица, смена адреса и неисправность машины появляются по ходу
смены. Следите за сообщениями. Столкновения портят кузов и груз; крепления
снижают повреждения. У гаража можно отремонтировать и заправить машину.
Если она застряла или перестала ехать, все выходят, а хост вызывает эвакуатор
через Esc: фургон возвращается в гараж с аварийным запасом топлива и теряет
1 очко репутации. Деньги для этого не нужны.

В гараже продаются три улучшения: 10 ячеек багажника ($800), автоматические
крепления ($650), расширение до 4 активных заказов ($1200). Роли курьера,
водителя, грузчика и диспетчера помогают распределить работу; действия доступны
каждому. NPC ходят по району, по улице движется декоративный полицейский патруль.
Полноценной системы преследования, оружия, большого открытого мира и голосового
чата в этой версии нет.

## Управление

| Клавиша | Действие |
| --- | --- |
| WASD | Движение относительно камеры; в машине — газ, задний ход и руль |
| Правая кнопка мыши + движение | Поворот камеры |
| Колесо мыши | Приблизить / отдалить камеру |
| E | Контекстное действие: взять, помочь нести, открыть дверь, сесть, выйти |
| F | Загрузить / взять груз сзади машины; передать у адреса доставки |
| G | Закрепить грузы в открытом багажнике |
| Q | Поставить груз на землю |
| Tab | Контракты, компания, помощь |
| M | Карта игроков, фургона и активных доставок |
| I | Выбрать груз в багажнике |
| Пробел | Тормоз |
| H | Сигнал фургона |
| R | Возрождение через 3 секунды после наезда |
| F5 | Сохранение мира хостом |
| Esc | Меню сессии / закрыть планшет |

Для посадки подойдите **сбоку** машины. Задняя сторона предназначена для груза.
Выйти можно только после остановки. С открытым багажником фургон не едет.
Открытый планшет или меню останавливают ваши команды движения, но общая смена
продолжается. Тяжёлый груз ведёт первый грузчик; второй может отпустить его Q.

## Сохранения и PlayerID

Профиль хранится локально в `%APPDATA%/Godot/app_userdata/After Hours/`.
`identity.key` определяет постоянный PlayerID: сохраняйте его вместе с
`profile.cfg` при переносе на другой компьютер. Не копируйте один профиль двум
одновременно играющим людям. Публичный ключ и одноразовая подпись позволяют
вернуть ваш прогресс без онлайн-регистрации.

Миры находятся только на компьютере хоста: `Saves/<имя_мира>/world.sav`.
Все домены хранятся одной атомарной транзакцией с контрольной суммой и резервной
копией `.bak`; это предотвращает расхождение денег, вещей и заказов. Сохранение
происходит каждые 30 секунд, при подключении, выходе клиента и завершении хостом.
Клиент хранит профиль и последние адреса, а не копию главного сохранения.

Загрузка версии 0.1 расширяет район и перемещает игроков к новому гаражу,
сохраняя WorldID, PlayerID, кошельки, статистику, предметы и старые заказы.
Ранее купленный склад даёт расширение гаража, наём работника — оборудование.
Записи прежних покупок и запас расходников сохраняются. Формат сохранения и
сетевой протокол новой версии — 2; смешанные версии не соединяются.

## Исходники и сборка

Godot **4.4.1 stable**, renderer Compatibility. Откройте `project.godot` в этой
версии редактора. Модели и анимации включены; Blender и платные плагины не нужны.

```sh
python tools/build_windows.py
```

Скрипт загружает официальный движок и Windows-шаблон соответствующей версии,
импортирует проект и создаёт `build/AfterHours-Windows.zip`. Для офлайн-сборки
передайте `--godot /path/to/godot --template /path/to/windows_release_x86_64.exe`.
Тестовые сцены и инструменты разработки исключены из готовой игры.

```sh
godot --headless --path . res://tests/core_tests.tscn
python tests/network_tests.py /path/to/godot
```

GitHub Actions проверяет правила, реальную сессию из 8 процессов, экспортирует
Windows-архив и запускает экспортированный EXE на Windows с проверкой host save.
Подробности и ограничения проверки: [docs/VALIDATION.md](docs/VALIDATION.md).

Модели, текстуры и анимации Kenney используются по CC0. Ссылки и условия:
[docs/ASSET-LICENSES.txt](docs/ASSET-LICENSES.txt). Звуки и фоновая музыка
синтезируются самой игрой. Лицензии Godot включены в архив.
